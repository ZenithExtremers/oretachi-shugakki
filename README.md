# 俺たちの秋学期

秋学期のテスト対策アプリ（PWA）。本番と同じ形式の5択問題で練習できる。

| 科目 | 内容 |
|---|---|
| C/C++プログラミング | 2026年度中間テストと同じ形式（30問・5択・行番号付きコード）。中間の30問を収録 |
| データベース | 第2〜7回（SQL）。実行結果の問題は MariaDB で答えを確認済み |
| ソフトウェア設計 | 第1・2・4〜7回（UML の図を読む問題） |

各科目に「基礎コース（レッスン）」「模試（30問）」「分野別」「間違えた問題の復習」がある。

スマホで開いて「ホーム画面に追加」するとアプリとして使える。オフラインでも動く。

問題や科目の追加は [docs/ADDING.md](docs/ADDING.md)。チェックは `node tools/verify.mjs`（g++ と MariaDB を使う）。
