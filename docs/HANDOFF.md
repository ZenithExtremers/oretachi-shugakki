## いつものルール
- 返事は日本語で短く
- 新機能や見た目を変えるときは、先に選択式で質問する（質問の中身は選択肢の説明に書く。質問の前に書いた文章はユーザーに見えない）。素材の追加だけなら質問なし
- docs/IDEAS.md のメモにある案は「アプデして」と言われてから実装
- 変更のたびに：data/patchnotes.js の先頭に追加（先頭のバージョンがアプリのバージョン）、sw.js の CACHE を1つ上げる（今は oretachi-v92）、390px 幅で Playwright 確認、コミットして push
- バージョン：左＝大きな節目、真ん中＝機能の追加、右＝小さな修正
- ユーザーの個人情報は使わない。キャラ・ロゴ・歌詞など既存作品のものは使わず、すべてオリジナル
- 強さの調整の基準：全員 Lv.50（★1・★2 は上限）、得意なし、正答率 80〜90%、ゲキムズ。結果を伝えるときは主人公 Lv・仲間 Lv・正答率・難易度を必ず書く。Lv.150 の主人公に合わせて敵を強くしない

## 主なファイル
- app.js：本編（ホーム・科目・問題・結果・苦手分析・追いこみ・学習カレンダー・設定）
- himakoroshi.js：ヒマコロシ（フクロウ・勉強・ゲーム・単語）。rpg.js・charart.js・history.js はヒマコロシを開いたときに読み込む
- rpg.js：冒険（バトル・ガチャ3種・図鑑・中間ボス・ラスボス・主人公のセリフ HLINE）
- charart.js：仲間のイラスト（SVG）／enemyart.js：敵のイラスト（「科目|名前」がキー、ヌルポだけ絵文字のまま）
- enemies.js・enemies-stage.js：敵のデータ
- data/<科目>/：問題・基礎コース。data/subjects.js に試験日（C/C++ 1/15・DB 1/6・設計 1/7）
- history.js・history-map.js・data/history/：歴史ゲーム
- docs/IDEAS.md：あとでやる案・保留リスト・バランスの基準
